# MatchPattern

Independent football match analysis and pattern-based prediction dashboard.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Routes

- `/` — redirects to the next-weekend board
- `/predictions/weekend` — next-weekend pattern board
- `/predictions` — historical prediction record

## Disclaimer

MatchPattern provides analysis and estimates for informational and entertainment purposes. Past results do not guarantee future outcomes.
